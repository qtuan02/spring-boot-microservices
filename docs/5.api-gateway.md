# API Gateway

**API Gateway** là cổng vào duy nhất (Entry Point) của hệ thống. Client (Web, Mobile) sẽ chỉ gọi đến Gateway, sau đó Gateway sẽ điều hướng request đến các service bên dưới (Catalog, Order).

## 1. Tech Stack

- **Framework**: Spring Cloud Gateway (dựa trên Spring WebFlux / Reactor netty).
- **Discovery**: Static Configuration (hiện tại), có thể nâng cấp lên Eureka/Consul sau.
- **Documentation**: SpringDoc OpenAPI (Aggregated Swagger UI).

## 2. Cấu Hình Cổng (Routing)

Gateway chạy tại port **8989** và định tuyến như sau:

- `/catalog/**` → Chuyển tiếp đến **Catalog Service** (localhost:8081).
- `/orders/**` → Chuyển tiếp đến **Order Service** (localhost:8082).
- `/v3/api-docs/**` → Tổng hợp OpenAPI docs từ các service con.

Cấu hình chi tiết trong `application.yml`:

```yaml
spring:
  cloud:
    gateway:
      routes:
        - id: catalog-service
          uri: ${CATALOG_SERVICE_URL:http://localhost:8081}
          predicates:
            - Path=/catalog/**
          filters:
            - RewritePath=/catalog/?(?<segment>.*), /${segment}

        - id: orders-service
          uri: ${ORDER_SERVICE_URL:http://localhost:8082}
          predicates:
            - Path=/orders/**
          filters:
            - RewritePath=/orders/?(?<segment>.*), /${segment}
```

## 3. Swagger UI Tổng Hợp

Thay vì truy cập từng swagger của từng service, bạn chỉ cần vào Gateway:

[http://localhost:8989/swagger-ui.html](http://localhost:8989/swagger-ui.html)

Tại đây bạn có thể chọn xem API của Catalog hoặc Order từ dropdown menu.

## 4. Cách Chạy

### Chạy Local (Dev Mode)

```bash
cd api-gateway
./mvnw spring-boot:run
# Windows: mvnw.cmd spring-boot:run
```

### Chạy với Docker

```bash
docker compose -f deployment/docker-compose/apps.yml up -d api-gateway
```

## 5. Testing

Thử gọi API thông qua Gateway:

1. **Lấy danh sách sản phẩm**:
   `GET http://localhost:8989/catalog/api/products`
   _(Gateway sẽ gọi sang `http://localhost:8081/api/products`)_

2. **Tạo đơn hàng**:
   `POST http://localhost:8989/orders/api/orders`
   _(Gateway sẽ gọi sang `http://localhost:8082/api/orders`)_
