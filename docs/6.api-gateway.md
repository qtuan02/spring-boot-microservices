# API Gateway

Cổng vào duy nhất (Single Entry Point) của hệ thống. Client chỉ cần biết địa chỉ Gateway, không cần biết từng service.

## Thông Tin Cơ Bản

- **Port**: 8989
- **Framework**: Spring Cloud Gateway (Reactive - WebFlux)
- **Swagger**: [http://localhost:8989/swagger-ui.html](http://localhost:8989/swagger-ui.html)

## Tại Sao Cần Gateway?

**Không có Gateway**:

```
Client phải biết địa chỉ TẤT CẢ services:
- Catalog: http://localhost:8081
- Inventory: http://localhost:8082
- Order: http://localhost:8083
→ Phức tạp, khó maintain
```

**Có Gateway**:

```
Client chỉ gọi: http://localhost:8989
→ Gateway tự route đến service phù hợp
```

**Lợi ích**:

- Client đơn giản hơn
- Centralized security (authen/author tại 1 điểm)
- Load balancing (khi có nhiều instances)
- API aggregation
- Centralized logging
- Rate limiting

## Routing

Gateway route dựa trên path prefix:

**Catalog Service** (`/catalog/**`):

```bash
# Client gọi
GET http://localhost:8989/catalog/api/products

# Gateway chuyển thành
GET http://localhost:8081/api/products
```

**Inventory Service** (`/inventory/**`):

```bash
GET http://localhost:8989/inventory/api/inventories/stocks
→ http://localhost:8082/api/inventories/stocks
```

**Order Service** (`/orders/**`):

```bash
POST http://localhost:8989/orders/api/orders
→ http://localhost:8083/api/orders
```

### Configuration

```yaml
spring:
  cloud:
    gateway:
      routes:
        - id: catalog-service
          uri: http://localhost:8081
          predicates:
            - Path=/catalog/**
          filters:
            - RewritePath=/catalog/(?<segment>.*), /${segment}
```

**Giải thích**:

- `uri`: Địa chỉ backend service
- `predicates`: Điều kiện để match (path)
- `filters`: Transform request (bỏ prefix)

**RewritePath filter**:

```
Input:  /catalog/api/products
Remove: /catalog
Output: /api/products
```

## Swagger Aggregation

Gateway tổng hợp Swagger UI của tất cả services:

```java
@Bean
List<GroupedOpenApi> apis() {
    return List.of(
        GroupedOpenApi.builder()
            .group("catalog-service")
            .pathsToMatch("/catalog/**")
            .build(),
        GroupedOpenApi.builder()
            .group("inventory-service")
            .pathsToMatch("/inventory/**")
            .build(),
        GroupedOpenApi.builder()
            .group("orders-service")
            .pathsToMatch("/orders/**")
            .build()
    );
}
```

**Cách dùng**:

1. Mở [http://localhost:8989/swagger-ui.html](http://localhost:8989/swagger-ui.html)
2. Chọn service từ dropdown (top-right)
3. Test APIs từ 1 nơi

## Reactive Architecture

Gateway dùng **Spring WebFlux** (reactive, non-blocking):

**Traditional (Tomcat)**:

- 1 request = 1 thread
- 1000 requests = 1000 threads

**Reactive (Netty)**:

- Non-blocking I/O
- 1000 requests = vài threads
- High throughput, low latency

## Filters

### Global Filters

Áp dụng cho tất cả requests:

```java
@Component
public class LoggingFilter implements GlobalFilter {
    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        log.info("Request: {} {}",
            exchange.getRequest().getMethod(),
            exchange.getRequest().getURI()
        );

        return chain.filter(exchange);
    }
}
```

### Route Filters

Chỉ áp dụng cho 1 route:

```yaml
routes:
  - id: catalog-service
    filters:
      - AddRequestHeader=X-Request-Source, API-Gateway
```

**Built-in filters có sẵn**:

- `AddRequestHeader` - Thêm header vào request
- `AddResponseHeader` - Thêm header vào response
- `CircuitBreaker` - Resilience4j integration
- `RateLimiter` - Giới hạn requests
- `Retry` - Tự động retry
- `SetPath`, `PrefixPath`, `StripPrefix` - Transform paths

## CORS Configuration

Cho phép web clients từ domain khác:

```yaml
spring:
  cloud:
    gateway:
      globalcors:
        cors-configurations:
          "[/**]":
            allowed-origins: "http://localhost:4200"
            allowed-methods:
              - GET
              - POST
              - PUT
              - DELETE
```

## Testing

```java
@Test
void shouldRoute() {
    // Mock backend
    wireMock.stubFor(get("/api/products")
        .willReturn(okJson("{\"data\":[]}")));

    // Call via Gateway
    given()
        .when().get("/catalog/api/products")
        .then().statusCode(200);

    // Verify forwarded
    wireMock.verify(getRequestedFor(urlEqualTo("/api/products")));
}
```

## Troubleshooting

**404 Not Found**:

- Check route config: `GET /actuator/gateway/routes`
- Verify path match: `/catalog/**` phải match `/catalog/api/products`
- Backend service có chạy không?

**503 Service Unavailable**:

- Backend service down
- URI sai (localhost vs container name trong Docker)

**Gateway không start**:

- Port 8989 bị chiếm
- Dependency conflict (WebFlux vs Web MVC)
