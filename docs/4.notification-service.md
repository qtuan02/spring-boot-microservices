# Notification Service

Service này chịu trách nhiệm gửi thông báo (email) đến người dùng khi có sự kiện quan trọng xảy ra trong hệ thống, ví dụ như đặt hàng thành công hay đơn hàng bị hủy.

## 1. Tech Stack

- **Framework**: Spring Boot 3.5.x
- **Message Broker**: RabbitMQ (Spring AMQP)
- **Email**: Java MailSender (Spring Boot Starter Mail)
- **Database**: PostgreSQL (lưu log nếu cần)

## 2. Cách Hoạt Động

Service hoạt động theo cơ chế **Event-Driven**:

1. Lắng nghe các message từ RabbitMQ Exchange `orders-exchange`.
2. Khi nhận được event (ví dụ `OrderCreatedEvent`, `OrderCancelledEvent`), service sẽ gửi email tương ứng đến khách hàng.

## 3. Cấu Hình

Các cấu hình quan trọng trong file `application.properties`:

- `server.port`: Port chạy service, mặc định là `8083`.
- `notification.order-events-exchange`: Tên RabbitMQ Exchange để lắng nghe, mặc định là `orders-exchange`.
- `notification.new-orders-queue`: Queue nhận event đơn hàng mới, mặc định là `new-orders`.
- `spring.mail.host`: SMTP Host (MailHog hoặc Gmail), mặc định là `localhost`.
- `spring.mail.port`: SMTP Port, mặc định là `1025`.

## 4. Cách Chạy

### Chạy trên máy (Dev Mode)

Trước khi chạy, đảm bảo:

- RabbitMQ đang chạy (Port 5672).
- Mail Server (MailHog) đang chạy (Port 1025). Nếu chỉ muốn test log thì không cần.

```bash
cd notification-service
./mvnw spring-boot:run
```

Service sẽ khởi động tại [http://localhost:8083](http://localhost:8083).

### Chạy với Docker

```bash
docker compose -f deployment/docker-compose/apps.yml up -d notification-service
```

## 5. Kiểm Tra

Service này không có API để gọi trực tiếp (trừ Actuator). Để test, bạn tạo đơn hàng từ **Order Service**:

1. Gọi API `POST /api/orders` bên Order Service.
2. Kiểm tra log của Notification Service, bạn sẽ thấy:
   ```text
   Received OrderCreatedEvent: OrderId=...
   Sending email to: ...
   ```
