# Catalog Service

Service quản lý danh mục sản phẩm - service read-heavy phục vụ việc hiển thị products.

## Thông Tin Cơ Bản

- **Port**: 8081
- **Swagger**: [http://localhost:8081/swagger-ui.html](http://localhost:8081/swagger-ui.html)
- **Database**: PostgreSQL (port 15432 khi chạy Docker)

## Chức Năng

Service này làm 3 việc chính:

- Xem danh sách sản phẩm (có phân trang, 10 sản phẩm/trang)
- Xem chi tiết 1 sản phẩm theo code
- Được Order Service gọi để validate sản phẩm khi tạo đơn

## API

### GET /api/products

Lấy danh sách sản phẩm.

**Query params**: `page` (số trang, mặc định 1)

**Response**:

```json
{
  "data": [
    {
      "code": "P001",
      "name": "Spring Boot in Action",
      "price": 29.99,
      "categoryName": "Programming",
      "authorName": "Craig Walls"
    }
  ],
  "totalElements": 100,
  "pageNumber": 1,
  "totalPages": 10,
  "isFirst": true,
  "isLast": false
}
```

### GET /api/products/{code}

Lấy chi tiết sản phẩm.

**Response**:

```json
{
  "code": "P001",
  "name": "Spring Boot in Action",
  "description": "Comprehensive guide...",
  "price": 29.99
}
```

Nếu không tìm thấy → 404 với message lỗi.

## Database

Service dùng 5 bảng:

**1. products** - Bảng chính

```sql
CREATE TABLE products (
    code        TEXT PRIMARY KEY,
    name        TEXT NOT NULL,
    description TEXT,
    price       NUMERIC NOT NULL,
    category_id BIGINT REFERENCES categories(id),
    author_id   BIGINT REFERENCES authors(id)
);
```

**2. categories** - Phân loại sản phẩm

```sql
CREATE TABLE categories (
    id   BIGINT PRIMARY KEY,
    name TEXT NOT NULL UNIQUE
);
```

**3. authors** - Tác giả/nhà sản xuất

```sql
CREATE TABLE authors (
    id    BIGINT PRIMARY KEY,
    name  TEXT NOT NULL,
    email TEXT
);
```

**4. tags** - Tags để search

```sql
CREATE TABLE tags (
    id   BIGINT PRIMARY KEY,
    name TEXT NOT NULL UNIQUE
);
```

**5. product_tags** - Link products và tags (many-to-many)

```sql
CREATE TABLE product_tags (
    product_id BIGINT,
    tag_id     BIGINT,
    PRIMARY KEY (product_id, tag_id)
);
```

**Relationships**:

- 1 Category → Nhiều Products
- 1 Author → Nhiều Products
- Products ↔ Tags (many-to-many)

## Integration

### Với API Gateway

Gateway route requests `/catalog/**` đến service này:

```bash
# Direct call
GET http://localhost:8081/api/products

# Via Gateway
GET http://localhost:8989/catalog/api/products
```

### Với Order Service

Khi tạo order, Order Service gọi sang đây để:

1. Check sản phẩm có tồn tại không
2. Validate giá có đúng không (chống manipulation)

```java
// HTTP client trong Order Service
@FeignClient(name = "catalog-service")
interface CatalogClient {
    @GetMapping("/api/products/{code}")
    Optional<Product> getProduct(@PathVariable String code);
}
```

## Configuration

```properties
server.port=8081
spring.datasource.url=${DB_URL:jdbc:postgresql://localhost:15432/postgres}
spring.datasource.username=${DB_USERNAME:postgres}
spring.datasource.password=${DB_PASSWORD:postgres}
```

Environment variables (Docker):

- `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`

## Testing

Service dùng **Testcontainers** để test:

```java
@SpringBootTest(webEnvironment = RANDOM_PORT)
@Testcontainers
class ProductTests {
    @Container
    static PostgreSQLContainer postgres = new PostgreSQLContainer("postgres:18");

    @Test
    void shouldGetProducts() {
        given()
            .when().get("/api/products")
            .then().statusCode(200);
    }
}
```

Lợi ích: Test với database thật, không mock.

## Troubleshooting

**Products không hiển thị**:

- Check Flyway migrations đã chạy chưa
- Verify có data test không (file `V9__add_books_data.sql`)
- Default page=1, không phải 0

**Database connection refused**:

```bash
# Check PostgreSQL
docker ps | grep catalog-db

# Check port
netstat -ano | findstr :15432
```

**Product not found**:

- Code phải unique trong DB
- Case-sensitive: "P001" khác "p001"
