# Catalog Service

Service quản lý danh mục sản phẩm trong hệ thống.

## 1. Thông Tin Cơ Bản

- **Port**: 8081
- **Swagger UI**: [http://localhost:8081/swagger-ui.html](http://localhost:8081/swagger-ui.html)
- **Database**: PostgreSQL (port 15432 khi chạy Docker)

## 2. Chức Năng

- Xem danh sách sản phẩm (có phân trang).
- Xem chi tiết sản phẩm theo mã code.

## 3. API

### GET /api/products

Lấy danh sách sản phẩm.

- **Query params**: `page` (số nguyên, mặc định là 1).
- **Response**:
  ```json
  {
    "data": [{ "code": "P001", "name": "Product", "price": 29.99 }],
    "totalElements": 100,
    "pageNumber": 1,
    "totalPages": 10
  }
  ```

### GET /api/products/{code}

Lấy chi tiết sản phẩm theo mã.

- **Response**:
  ```json
  { "code": "P001", "name": "Product", "description": "...", "price": 29.99 }
  ```

## 4. Database

Bảng **`products`** gồm các cột:

- `id` (BIGINT): Khóa chính.
- `code` (TEXT): Mã sản phẩm (unique).
- `name` (TEXT): Tên sản phẩm.
- `description` (TEXT): Mô tả.
- `image_url` (TEXT): URL ảnh.
- `price` (NUMERIC): Giá.

## 5. Dependencies

Các thư viện chính được sử dụng:

- **spring-boot-starter-web**: Xây dựng REST API.
- **spring-boot-starter-data-jpa**: Kết nối database với JPA/Hibernate.
- **spring-boot-starter-validation**: Validation dữ liệu đầu vào.
- **postgresql**: Driver kết nối PostgreSQL.
- **flyway-core**: Quản lý database migration.
- **springdoc-openapi**: Tự động tạo Swagger UI.
- **spring-boot-starter-actuator**: Health check và Metrics.

## 6. Lệnh Thường Dùng

```bash
./mvnw spring-boot:run          # Chạy ứng dụng
./mvnw test                     # Chạy tests
./mvnw spotless:apply           # Format code
./mvnw spring-boot:build-image  # Build Docker image
```
