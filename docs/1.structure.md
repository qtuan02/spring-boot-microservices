# Cấu Trúc & Architecture

## 1. System Architecture

Hệ thống Microservices với giao tiếp đồng bộ (HTTP) và bất đồng bộ (RabbitMQ):

```text
                                           ┌──────────────────┐
                                      ┌───▶│  Catalog Service │
                                      │    │   (Port 8081)    │
                                      │    └──────────────────┘
                                      │
┌────────┐       ┌─────────────┐      │    ┌──────────────────┐       ┌──────────┐
│  User  │─────▶│ API Gateway │──────┼───▶│  Order Service   │─────▶│ RabbitMQ │
└────────┘       │ (Port 8989) │      │    │   (Port 8082)    │       └─────┬────┘
                 └─────────────┘      │    └──────────────────┘             │
                                      │                                     │
                                      │    ┌──────────────────┐             │
                                      └───▶│   Notification   │◀───────────┘
                                           │     Service      │
                                           │   (Port 8083)    │
                                           └──────────────────┘

Flow:
  1. User gọi API thông qua API Gateway (cổng duy nhất)
  2. Gateway điều hướng đến Catalog hoặc Order Service
  3. Order Service publish event sang RabbitMQ
  4. Notification Service consume event và gửi email
```

## 2. Monorepo Structure

Cấu trúc tổng quan của toàn bộ Repository:

```text
spring-boot-microservices/
├── .github/workflows/           # CI/CD Pipelines (GitHub Actions)
│   ├── api-gateway.yml
│   ├── catalog-service.yml
│   ├── notification-service.yml
│   └── order-service.yml
├── deployment/                  # Deployment Configurations
│   └── docker-compose/
│       ├── infra.yml            # PostgreSQL, RabbitMQ, MailHog
│       └── apps.yml             # Catalog, Order, Notification, Gateway
├── docs/                        # Tài liệu dự án
├── api-gateway/                 # API Gateway (Port 8989)
├── catalog-service/             # Catalog Service (Port 8081)
├── order-service/               # Order Service (Port 8082)
├── notification-service/        # Notification Service (Port 8083)
├── template-service/            # Template để tạo service mới

├── Taskfile.yml                 # Task Runner (shortcuts lệnh)
├── .sdkmanrc                    # Cấu hình Java/Maven (Mac/Linux)
├── .gitignore
└── README.md
```

## 3. Microservice Structure

Mỗi service được tổ chức theo **Layered Architecture**, lấy cảm hứng từ **Hexagonal Architecture**.

### Các lớp chính

- **Web Layer**: Giao tiếp với bên ngoài (REST API), validate dữ liệu. Không chứa logic nghiệp vụ.
- **Domain Layer**: Trái tim của ứng dụng. Chứa Entity và Service (logic nghiệp vụ).
- **Config Layer**: Cấu hình kết nối database, RabbitMQ, Swagger.

### Cấu trúc chi tiết

```text
[service-name]/
├── src/
│   ├── main/
│   │   ├── java/com/qtuan02/[service]/
│   │   │   ├── *Application.java        # Điểm khởi chạy Spring Boot
│   │   │   ├── ApplicationProperties.java
│   │   │   │
│   │   │   ├── web/                     # [WEB LAYER]
│   │   │   │   ├── controllers/         # REST Controllers
│   │   │   │   └── exceptions/          # Global Exception Handler
│   │   │   │
│   │   │   ├── domain/                  # [DOMAIN LAYER]
│   │   │   │   ├── models/              # Value Objects, Enums
│   │   │   │   ├── *Entity.java         # JPA Entities
│   │   │   │   ├── *Repository.java     # Spring Data JPA
│   │   │   │   ├── *Service.java        # Business Logic
│   │   │   │   └── *Mapper.java         # Entity <-> DTO
│   │   │   │
│   │   │   ├── config/                  # [CONFIG]
│   │   │   │   ├── SwaggerConfig.java
│   │   │   │   └── RabbitMQConfig.java  # (nếu dùng RabbitMQ)
│   │   │   │
│   │   │   ├── clients/                 # [CLIENTS] Gọi service khác
│   │   │   │   └── *Client.java
│   │   │   │
│   │   │   ├── events/                  # [EVENTS] Event handlers (Notification)
│   │   │   │   └── *EventHandler.java
│   │   │   │
│   │   │   └── jobs/                    # [JOBS] Scheduled tasks
│   │   │       └── *Job.java
│   │   │
│   │   └── resources/
│   │       ├── application.properties   # Cấu hình chính
│   │       └── db/migration/            # Flyway migrations
│   │           ├── V1__create_tables.sql
│   │           └── V2__insert_data.sql
│   │
│   └── test/
│       ├── java/com/qtuan02/[service]/
│       │   ├── *ApplicationTests.java   # Context load test
│       │   ├── *ControllerTests.java    # API tests
│       │   └── *ServiceTests.java       # Unit tests
│       │
│       └── resources/
│           └── application-test.properties
│
├── pom.xml                              # Maven dependencies
└── mvnw, mvnw.cmd                       # Maven wrapper
```
