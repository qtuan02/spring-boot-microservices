# Order Service

Service quản lý đơn hàng. Khi tạo đơn mới, nó sẽ gọi sang Catalog Service để kiểm tra sản phẩm hợp lệ, sau đó gửi event sang RabbitMQ để các service khác xử lý tiếp.

## 1. Thông Tin Cơ Bản

- **Port**: 8082
- **Swagger UI**: [http://localhost:8082/swagger-ui.html](http://localhost:8082/swagger-ui.html)
- **Database**: PostgreSQL (port 25432 khi chạy Docker)
- **Message Broker**: RabbitMQ (localhost:5672)

## 2. Chức Năng

- Tạo đơn hàng mới (tự động validate sản phẩm từ Catalog Service).
- Xem danh sách đơn hàng của user.
- Xem chi tiết một đơn hàng.
- Xử lý sự kiện theo mô hình Transactional Outbox Pattern.

## 3. API

### POST /api/orders

Tạo đơn hàng mới.

- **Request**:
  ```json
  {
    "customer": { "name": "A", "email": "a@a.com", "phone": "123" },
    "deliveryAddress": { "addressLine1": "123 St", "country": "VN" },
    "items": [{ "code": "P001", "price": 29.99, "quantity": 2 }]
  }
  ```
- **Response**: `{ "orderNumber": "550e8400-e29b..." }`

### GET /api/orders

Lấy danh sách đơn hàng của user hiện tại.

## 4. Database

### Bảng `orders`

Lưu thông tin chính của đơn hàng:

- `order_number` (UUID): Mã đơn hàng.
- `status`: Trạng thái (NEW, IN_PROCESS, DELIVERED, CANCELLED...).

### Bảng `order_items`

Lưu chi tiết các sản phẩm trong đơn hàng.

### Bảng `order_events` (Outbox)

Lưu các event trước khi gửi sang RabbitMQ. Đây là cách triển khai **Transactional Outbox Pattern** để đảm bảo event không bị mất.

## 5. RabbitMQ

- **Exchange**: `orders-exchange`
- **Queues**: `new-orders`, `delivered-orders`, `cancelled-orders`, `error-orders`

## 6. Scheduled Jobs

Service có 2 job chạy định kỳ:

- **OrderEventPublishingJob** (mỗi 5 giây): Đọc bảng `order_events` và gửi message lên RabbitMQ.
- **OrderProcessingJob** (mỗi 10 giây): Xử lý các đơn hàng mới theo logic nghiệp vụ.

## 7. Resilience4j

Khi gọi sang Catalog Service, hệ thống áp dụng các cơ chế chống lỗi:

- **Retry**: Tự động thử lại tối đa 2 lần nếu request thất bại.
- **Circuit Breaker**: Ngắt mạch nếu tỷ lệ lỗi vượt quá 50%.

## 8. Dependencies

Các thư viện bổ sung so với Catalog Service:

- **spring-boot-starter-amqp**: Kết nối RabbitMQ.
- **resilience4j-spring-boot3**: Retry và Circuit Breaker.
- **shedlock-spring**: Distributed Locking cho các Scheduled Jobs.
- **wiremock**: Mock server để test gọi HTTP.

## 9. Lệnh Thường Dùng

```bash
./mvnw spring-boot:run          # Chạy ứng dụng
./mvnw test                     # Chạy tests
./mvnw spotless:apply           # Format code
./mvnw spring-boot:build-image  # Build Docker image
```
