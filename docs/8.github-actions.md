# CI/CD với GitHub Actions

CI/CD pipelines tự động build, test và deploy services khi có code changes.

## Tổng Quan

**Pipeline flow**:

```
1. Developer push code → GitHub
2. GitHub Actions trigger workflow
3. Checkout code
4. Setup Java 21
5. Run tests (mvnw verify)
6. Build Docker image (Buildpacks)
7. Push image → Docker Hub
```

## Khi Nào Chạy?

### Triggers

**Push to main**:

```yaml
on:
  push:
    branches: ["main"]
    paths:
      - catalog-service/**
```

**Pull Request**:

```yaml
on:
  pull_request:
    branches: ["main"]
    paths:
      - catalog-service/**
```

### Path Filters

Pipeline chỉ chạy khi files trong service folder thay đổi:

**Scenarios**:

- Sửa `catalog-service/src/...` → ✅ Chạy catalog-service.yml
- Sửa `order-service/pom.xml` → ✅ Chạy order-service.yml only
- Sửa `README.md` → ❌ Không chạy gì

**Lợi ích**: Tiết kiệm thời gian và GitHub Actions minutes

## Workflow Structure

```
.github/workflows/
├── catalog-service.yml

├── order-service.yml
├── notification-service.yml
└── api-gateway.yml
```

Mỗi service có workflow riêng → độc lập.

### Workflow Example

```yaml
name: Catalog Service CI

on:
  push:
    paths: ["catalog-service/**"]
    branches: ["main"]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v5

      - name: Setup Java 21
        uses: actions/setup-java@v5
        with:
          java-version: "21"
          distribution: "temurin"
          cache: "maven"

      - name: Build & Test
        run: chmod +x mvnw && ./mvnw -ntp verify

      - name: Login Docker Hub
        if: github.ref == 'refs/heads/main'
        uses: docker/login-action@v3
        with:
          username: ${{ secrets.DOCKERHUB_USERNAME }}
          password: ${{ secrets.DOCKERHUB_TOKEN }}

      - name: Build & Push Image
        if: github.ref == 'refs/heads/main'
        run: |
          ./mvnw spring-boot:build-image -DskipTests
          docker push qtuan02/ecommerce-catalog-service
```

## Pipeline Steps

### 1. Checkout Code

```yaml
- uses: actions/checkout@v5
```

Download source từ repo.

### 2. Setup Java

```yaml
- uses: actions/setup-java@v5
  with:
    java-version: "21"
    distribution: "temurin"
    cache: "maven"
```

**Maven cache**: Lần build sau nhanh hơn vì không download lại dependencies.

### 3. Build & Test

```yaml
- run: chmod +x mvnw && ./mvnw -ntp verify
```

**Chạy**:

- Compile code
- Unit tests
- Integration tests (Testcontainers)
- Package JAR

**Nếu tests fail** → Pipeline stops ❌

### 4. Login Docker Hub

```yaml
- if: github.ref == 'refs/heads/main'
  uses: docker/login-action@v3
  with:
    username: ${{ secrets.DOCKERHUB_USERNAME }}
    password: ${{ secrets.DOCKERHUB_TOKEN }}
```

**Chỉ chạy trên main branch** - không login cho PRs.

### 5. Build & Push Image

```yaml
- if: github.ref == 'refs/heads/main'
  run: |
    ./mvnw spring-boot:build-image -DskipTests
    docker push qtuan02/ecommerce-catalog-service
```

Build image với Buildpacks, push lên Docker Hub.

## GitHub Secrets

Cần setup 2 secrets:

**Vào**: Repository Settings → Secrets → Actions → New secret

**Secrets**:

- `DOCKERHUB_USERNAME` - Docker Hub username (ví dụ: `qtuan02`)
- `DOCKERHUB_TOKEN` - Access token từ Docker Hub

### Tạo Docker Hub Token

1. Login Docker Hub → Account Settings
2. Security → Access Tokens
3. New Access Token
   - Description: "GitHub Actions"
   - Permissions: Read, Write
4. Copy token → Save vào GitHub Secrets

> Token chỉ hiện 1 lần, lưu ngay!

## Image Tagging

**Current**: Tag `latest`

```bash
docker push qtuan02/ecommerce-catalog-service:latest
```

**Better**: Semantic versioning

```bash
VERSION=1.2.3
docker push qtuan02/ecommerce-catalog-service:$VERSION
docker push qtuan02/ecommerce-catalog-service:latest
```

**Or**: Git SHA

```bash
SHA=$(git rev-parse --short HEAD)
docker push qtuan02/ecommerce-catalog-service:$SHA
```

## Caching

**Maven dependencies**:

```yaml
- uses: actions/setup-java@v5
  with:
    cache: "maven"
```

**Tăng tốc**:

- First run: 5 minutes
- Subsequent runs: 2 minutes

## Troubleshooting

**Tests fail in CI nhưng pass local**:

- Check Java version khác nhau
- Missing environment variables
- Testcontainers timeout

**Docker push failed**:

```
Error: denied: access denied
```

**Fix**:

- Verify `DOCKERHUB_USERNAME` và `DOCKERHUB_TOKEN`
- Check token permissions
- Token expired → Tạo mới

**Maven download slow**:

```yaml
# Enable caching
with:
  cache: "maven"
```
