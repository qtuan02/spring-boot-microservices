# Notification Service

Service gửi email notifications - hoạt động hoàn toàn qua events, không có public API.

## Thông Tin Cơ Bản

- **Port**: 8084
- **Database**: PostgreSQL (port 45432)
- **Message Broker**: RabbitMQ
- **Mail Server**: MailHog (dev) hoặc SMTP (production)

> Service này không có REST API - chỉ consume events từ RabbitMQ.

## Cách Hoạt Động

Service lắng nghe events từ RabbitMQ và gửi email tương ứng:

```
1. Order Service publish event lên RabbitMQ
2. Notification Service nhận event
3. Build email content
4. Gửi email qua MailSender
5. Log kết quả
```

## Event Handlers

Service xử lý 4 loại events:

### 1. OrderCreatedEvent

**Queue**: `new-orders`

**Email**:

```
Subject: Order Confirmation - #550e8400

Dear Nguyen Van A,

Your order #550e8400 has been created successfully.

Order Items:
- Spring Boot in Action x 2

We'll notify you when delivered.
```

### 2. OrderDeliveredEvent

**Queue**: `delivered-orders`

**Email**: "Your order has been delivered!"

### 3. OrderCancelledEvent

**Queue**: `cancelled-orders`

**Payload** có thêm `reason`:

```json
{
  "orderNumber": "...",
  "reason": "Can't deliver to this location"
}
```

**Email**: "Your order has been cancelled. Reason: ..."

### 4. OrderErrorEvent

**Queue**: `error-orders`

**Email**: Internal notification (gửi admin/support team)

## RabbitMQ Setup

Service tự động tạo queues và bindings khi start:

```java
@Bean
Queue newOrdersQueue() {
    return new Queue("new-orders", true);  // durable
}

@Bean
Binding binding(TopicExchange exchange) {
    return BindingBuilder
        .bind(newOrdersQueue())
        .to(exchange)
        .with("order.created");
}
```

**Message consumption**:

```java
@RabbitListener(queues = "new-orders")
void handleOrderCreated(OrderCreatedEvent event) {
    log.info("Received: {}", event.getOrderNumber());
    String email = buildEmail(event);
    mailSender.send(event.getCustomerEmail(), "Order Confirmation", email);
}
```

**Error handling**: Nếu gửi email fail → Log error, không requeue (tránh infinite loop).

##Email Configuration

### Development (MailHog)

MailHog là fake SMTP server để test email:

```properties
spring.mail.host=localhost
spring.mail.port=1025
spring.mail.properties.mail.smtp.auth=false
```

**Web UI**: [http://localhost:8025](http://localhost:8025) - Xem tất cả emails đã gửi

### Production (Gmail Example)

```properties
spring.mail.host=smtp.gmail.com
spring.mail.port=587
spring.mail.username=your-email@gmail.com
spring.mail.password=your-app-password
spring.mail.properties.mail.smtp.auth=true
spring.mail.properties.mail.smtp.starttls.enable=true
```

> **Lưu ý**: Gmail cần tạo App Password thay vì dùng password thường.

### Integration Test

```java
@Test
void shouldSendEmail() {
    OrderCreatedEvent event = new OrderCreatedEvent(...);

    rabbitTemplate.send("orders-exchange", "order.created", event);

    await().atMost(5, SECONDS).untilAsserted(() -> {

    });
}
```

## Troubleshooting

**Messages không được consume**:

- RabbitMQ có chạy không: `docker ps | grep rabbitmq`
- Queues đã tạo chưa: Check RabbitMQ Management UI
- Service có kết nối được RabbitMQ không: Xem logs

**Email không gửi**:

- MailHog có chạy không: `docker ps | grep mailhog`
- Port 1025 available không
- Production SMTP: Verify credentials

**Duplicate emails**:

- Có nhiều instances chạy không?
- Mỗi instance sẽ consume messages → duplicate processing
- Solution: Chỉ chạy 1 instance hoặc dùng consumer groups

## Production Tips

### 1. Email Templates

Nên dùng template engine thay vì hardcode:

```java
String emailBody = templateEngine.process(
    "order-confirmation",
    Map.of("orderNumber", event.getOrderNumber())
);
```

### 2. Dead Letter Queue

Config DLQ cho failed messages:

```java
@Bean
Queue dlq() {
    return new Queue("dlq.new-orders");
}

@Bean
Queue newOrdersQueue() {
    return QueueBuilder.durable("new-orders")
        .withArgument("x-dead-letter-exchange", "dlx")
        .build();
}
```

### 3. Rate Limiting

Tránh spam SMTP server:

```java
@RateLimiter(name = "email")
public void sendEmail(String to, String subject, String body) {
    mailSender.send(to, subject, body);
}
```
